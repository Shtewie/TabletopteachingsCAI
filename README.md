# Tabletop Teachings — website

This is a plain, static website: HTML, CSS and a little vanilla JavaScript.
No build step, no framework, no `npm install`. Any browser (and Netlify)
can serve these files exactly as they are.

## File map

```
index.html              → the homepage (includes a "live adventures" teaser
                           section rendered by js/home-quests.js)
adventures/index.html   → the "Live Adventures" page (shell only — content
                           is rendered by JS from adventures-data.js)
css/style.css            → all styling (colours, fonts, layout)
js/adventures-data.js    → the campaign content — edit THIS to update
                           the Adventures page (and homepage teaser), not
                           the HTML
js/adventures.js         → renders adventures-data.js onto the Adventures
                           page and handles the campaign/tab switching
js/home-quests.js        → renders the first 3 campaigns from
                           adventures-data.js into the homepage's
                           #home-quests-grid teaser
favicon.ico, robots.txt  → site basics
netlify.toml             → Netlify hosting config (headers, redirects)
404.html                 → shown for any missing page
```

## Making everyday content edits

**Homepage text** (the six "What We Stand For" cards, the three "How To
Join" steps, the contact blurb): edit the text directly inside
`index.html`. Each card/step is a plain HTML block — just change the
words between the tags.

**Adventures / campaigns**: don't touch `adventures/index.html`. Instead
edit `js/adventures-data.js` — it's a plain list of campaigns with
comments explaining each field (name, tagline, world log entries,
characters, learning objectives). Copy an existing campaign block to add
a new one, or delete a block to remove one.

**Colours / fonts**: all defined at the top of `css/style.css` under
`:root`. The site uses six "quest" colour tones (`--quest-1` through
`--quest-6`) that are reused across cards, tags and badges.

## Running it locally

No install needed. From this folder, run any static file server, e.g.:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

(Opening `index.html` directly by double-clicking works for the homepage,
but the Adventures page and root-relative asset paths like `/css/style.css`
need an actual server — even a simple one — to resolve correctly.)

## Deploying on Netlify

1. Push this folder's contents to the root of your GitHub repo (replacing
   the old Lovable/TanStack project files).
2. In Netlify: **Site settings → Build & deploy → Build settings**
   - Build command: *(leave blank — there's nothing to build)*
   - Publish directory: `.` (repo root)
3. Save. Every push to your main branch will redeploy automatically.

That's it — no serverless functions, no Node runtime, no build minutes
used. This is a meaningful shift from how the site was set up before, so
see the note below.

## Note on how this site used to be built

The previous version of this site was generated by
[Lovable](https://lovable.dev), which scaffolds every project with a full
React + server-rendering stack (TanStack Start, React Query, ~45 UI
components) by default — regardless of whether the site needs it. This
site didn't: it's two pages of static content with no logins, no
database, and no dynamic data, so all of that machinery was pure
overhead — a much heavier download for visitors and a fragile serverless
deploy for something that can just be flat files.

This version has no dependency on Lovable, React, or any build tool.
If you want to keep making changes with an AI assistant going forward,
plain-language requests like "add a new campaign called X" or "change
the accent colour to blue" work well — just point it at this repo.
